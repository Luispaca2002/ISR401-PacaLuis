## Instrucciones de Compilación

Para cumplir con el criterio de reproducibilidad de la actividad FORM-TL-01, a continuación se detallan los parámetros para compilar este documento:

* **Compilador:** pdfLaTeX
* **Archivo principal:** `main.tex`
* **Dependencias:** TeX Live (o MiKTeX) con los paquetes estándar (`article`, `geometry`, `tabularx`, `booktabs`, `hyperref`).

### Orden de comandos en la Terminal
Ejecutar los siguientes comandos en la raíz del repositorio:
1. `pdflatex main.tex`
2. `pdflatex main.tex` (Se ejecuta dos veces para resolver las referencias cruzadas)
